## Oversikt

Pulserende flate som holder plassen til innhold som lastes (tekstlinjer, avatarer,
bilder/kort). Skjult for skjermlesere — kombiner med synlig lastetekst eller
`aria-busy` på containeren rundt.

## Varianter

### Egenskaper (Figma)

| Property | Values | Default | Notes |
|----------|--------|---------|-------|
| **Variant** (Variant) | Text, Circle, Rectangle | Text | Styrer default bredde/høyde/radius. Kan overstyres med `width`/`height`. |

3 varianter totalt — ingen boolske eller tekst-egenskaper.

## Tokens

### Spacing / geometri

| Variant | Bredde | Høyde | Radius |
|---------|--------|-------|--------|
| Text | 100% | `--size-16` (16px) | `--radius-4` (4px) |
| Circle | `--size-48` (48px) | `--size-48` (48px) | `--radius-999` (999px) |
| Rectangle | 100% | `--size-64` (64px) | `--radius-12` (12px) |

### Animasjon

| Property | Token | Value |
|----------|-------|-------|
| Varighet | `--duration-1000` | 1000ms |
| Kurve | — | `ease-in-out infinite alternate` |

### Farge

| Element | Token |
|---------|-------|
| Bakgrunn | `--color-system-neutral-weak` |

<Note>
  `width`/`height`-props overstyrer default-verdiene per variant via inline `style`
  — nyttig for f.eks. en 60%-bred tekstlinje i en flerlinjers lasteplassholder.
</Note>

### Variant-definisjon

```tsx
const variantClass: Record<SkeletonVariant, string> = {
  text: styles.text,
  circle: styles.circle,
  rectangle: styles.rectangle,
};
```

### Komponent-API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"text" \| "circle" \| "rectangle"` | `"text"` | Form på lasteplassholderen. |
| `width` | `CSSProperties["width"]` | — | Bredde, f.eks. `240` eller `"100%"`. Overstyrer variant-default. |
| `height` | `CSSProperties["height"]` | — | Høyde. Text og Circle har fornuftige standarder fra tokens. |
| `...rest` | `HTMLAttributes<HTMLDivElement>` | — | Alle native div-attributter spres på root-elementet. |

### Eksempler

```tsx
// Tekstlinje (default)
<Skeleton />

// Sirkel (avatar)
<Skeleton variant="circle" />

// Rektangel (bilde/kort)
<Skeleton variant="rectangle" />

// Sammensatt eksempel — kort som laster
<div style={{ display: "flex", gap: 16, alignItems: "flex-start" }} aria-busy="true">
  <Skeleton variant="circle" />
  <div style={{ flex: 1, display: "flex", flexDirection: "column", gap: 8 }}>
    <Skeleton width="60%" />
    <Skeleton />
    <Skeleton variant="rectangle" />
  </div>
</div>
```

## Tilgjengelighet

- `aria-hidden="true"` settes alltid på root-elementet — skeletonen er kun et
  visuelt lastesignal og skal ikke annonseres av skjermlesere.
- Sett `aria-busy="true"` på den *omsluttende* containeren (se eksempel over) og/eller
  synlig lastetekst, slik at hjelpeteknologi får et lastesignal.
- Respekterer `prefers-reduced-motion: reduce` — animasjonen slås av og flaten vises
  statisk.
