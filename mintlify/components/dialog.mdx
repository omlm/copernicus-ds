## Oversikt

Et native `<dialog>`-element vist med `showModal()`, så fokusfelle, `Escape`-lukking
og backdrop kommer gratis fra nettleseren. Kontrolleres med `open` og `onClose`.

## Anatomi

```
Dialog (DIALOG, showModal()) — ::backdrop mørklegger bak
└── Panel (DIV)
    ├── Header (DIV)
    │   ├── Title (P) — vises kun hvis satt
    │   └── Close (BUTTON, Lucide "X")
    ├── Body (DIV) — vises kun hvis children er satt
    └── Actions (DIV) — vises kun hvis satt, høyrejustert
```

## Sammensetning

Figma-eksemplet (node `3211:3`, 420×200) viser én fast variant med tre navngitte
seksjoner:

| Figma-seksjon | Kode-prop | Type | Notes |
|---|---|---|---|
| Header → Title | `title` | `ReactNode` | Vises kun hvis satt (ingen tom overskrift-plass). |
| Body | `children` | `ReactNode` | Brødtekst/innhold. |
| Actions | `actions` | `ReactNode` | Handlingsknapper nederst til høyre, f.eks. `<Button>`-er. |
| — (styrer selve visningen) | `open` | `boolean` (påkrevd) | Finnes ikke som Figma-egenskap — dialogen er alltid "åpen" i designet. |
| — (lukkeknapp, alltid i Header) | `onClose` | `() => void` | Kalles fra Escape, backdrop-klikk og X-knappen. |

### Komponent-API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | — (påkrevd) | Om dialogen vises (som modal, med backdrop). |
| `title` | `ReactNode` | — | Overskrift (Figma: "Title"). |
| `children` | `ReactNode` | — | Brødtekst/innhold (Figma: "Body"). |
| `actions` | `ReactNode` | — | Handlingsknapper nederst til høyre (Figma: "Actions"). |
| `onClose` | `() => void` | — | Kalles når dialogen lukkes (Escape, backdrop-klikk eller lukkeknappen). |
| `...rest` | `DialogHTMLAttributes<HTMLDialogElement>` (uten `open`/`title`) | — | Native `<dialog>`-attributter spres på rot-elementet. |

### Eksempler

```tsx
const [open, setOpen] = useState(false);

<Dialog
  open={open}
  title="Slett element?"
  onClose={() => setOpen(false)}
  actions={
    <>
      <Button variant="tertiary" onClick={() => setOpen(false)}>Avbryt</Button>
      <Button tone="danger" onClick={handleDelete}>Slett</Button>
    </>
  }
>
  Dette kan ikke angres.
</Dialog>
```

## Tilgjengelighet

- Native `<dialog>` + `showModal()` gir fokusfelle og `Escape`-lukking uten egen JS.
- Klikk på `::backdrop` (utenfor panelet) lukker dialogen via `onClose`.
- Lukkeknappen har `aria-label="Lukk"`; X-ikonet er dekorativt (`aria-hidden`).
- `<title>`-teksten er en vanlig `<p>`, ikke koblet med `aria-labelledby` — vurder å
  legge til om dialogens tilgjengelige navn må matche tittelen eksplisitt.
