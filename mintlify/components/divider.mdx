## Oversikt

Skillelinje for visuell separasjon av innhold — horisontalt mellom seksjoner, eller
vertikalt mellom elementer i en rad. Bygges på native `hr` for korrekt semantikk.

## Varianter

### Egenskaper (Figma)

| Property | Values | Default | Notes |
|----------|--------|---------|-------|
| **Orientation** (Variant) | Horizontal, Vertical | Horizontal | Horizontal = full bredde, 1px høyde. Vertical = fyller foreldrehøyden, 1px bredde. |

2 varianter totalt — ingen boolske eller tekst-egenskaper.

## Tokens

### Spacing / geometri

| Property | Token | Value |
|----------|-------|-------|
| Tykkelse (begge retninger) | `--border-width-1` | 1px |
| Min-høyde (Vertical) | `--size-24` | 24px |

### Farge

| Element | Token | Notes |
|---------|-------|-------|
| Linje | `--color-border-default` | Samme token uavhengig av retning. |

| File | Role |
|------|------|

### Import

```tsx
import { Divider, type DividerProps } from "src/components";
```

### Variant-definisjon

```tsx
const classes = [
  styles.divider,
  orientation === "vertical" ? styles.vertical : styles.horizontal,
  className,
]
  .filter(Boolean)
  .join(" ");
```

### Komponent-API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Retning på skillelinjen. |
| `...rest` | `HTMLAttributes<HTMLHRElement>` | — | Alle native `hr`-attributter spres på root-elementet. |

### Eksempler

```tsx
// Horisontal (default)
<Divider />

// Vertikal — i en horisontal rad
<div style={{ display: "flex", gap: 16, alignItems: "center", height: 48 }}>
  <span>Venstre</span>
  <Divider orientation="vertical" />
  <span>Høyre</span>
</div>
```

## Tilgjengelighet

- Renderes som native `<hr>` — får implisitt `role="separator"` fra skjermlesere.
- `aria-orientation` settes eksplisitt ut fra `orientation`-propen.
- Rent visuelt element uten interaksjon — ingen tastaturhensyn.
