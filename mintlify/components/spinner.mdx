## Oversikt

En 270°-bue over et subtilt spor som roterer kontinuerlig — indikerer at noe
laster, uten å vise fremdrift. Geometrien matcher Figma-komponenten: ringtykkelsen
er 20 % av radius i alle størrelser.

## Anatomi

```
Spinner (SPAN, role="status", aria-label) — animation: spin 1s linear infinite
└── svg (viewBox 0 0 40 40)
    ├── Track (CIRCLE) — statisk bakgrunnsring
    └── Indicator (CIRCLE) — roterende bue (strokeDasharray, rotert -90°)
```

## Varianter

### Egenskaper (Figma)

| Property | Values | Default | Notes |
|----------|--------|---------|-------|
| **Size** (Variant) | X-Small, Small, Medium, Large, X-Large | Medium | Figma har 5 faste størrelser — samsvarer 1:1 med kodens `SpinnerSize`. |

| Token | Peker på / Value |
|-------|-------------------|
| `--spinner-size-x-small` | `--size-12` (12px) |
| `--spinner-size-small` | `--size-16` (16px) |
| `--spinner-size-medium` | `--size-24` (24px) |
| `--spinner-size-large` | `--size-40` (40px) |

| `--spinner-color-track` | `--color-system-neutral-weak` |
| `--spinner-color-indicator` | `--color-foreground-action` |
| `--spinner-animation-duration` | `--duration-1000` (1000ms) |

### Komponent-API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `"x-small" \| "small" \| "medium" \| "large" \| "x-large"` | `"medium"` | Størrelsen (Figma: "Size"). |
| `label` | `string` | `"Loading…"` | Tilgjengelig etikett som leses opp av skjermlesere. |
| `...rest` | `HTMLAttributes<HTMLSpanElement>` | — | Native span-attributter spres på rot-elementet. |

### Eksempler

```tsx
<Spinner />
<Spinner size="small" />
<Spinner size="x-large" label="Laster resultater" />
```

## Tilgjengelighet

- `role="status"` + `aria-label` (default `"Loading…"`, overstyrbar via `label`) — annonseres av skjermlesere uten å avbryte.
- SVG-en er `aria-hidden` og `focusable="false"` — det tilgjengelige navnet kommer kun fra `aria-label` på rot-elementet.
- `prefers-reduced-motion: reduce` gjør rotasjonen 3× langsommere i stedet for å stoppe helt — bevegelsen formidler fortsatt at noe pågår, uten kraftig animasjon.
