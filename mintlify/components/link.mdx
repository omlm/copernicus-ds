## Oversikt

Lenke i aksjonsfargen med understrek, for navigasjon som endrer URL. For handlinger
brukeren utfører (send inn, fortsett, avvis), bruk `Button` i stedet.

### Typografi

| Element | Font | Weight | Size |
|---------|------|--------|------|
| Lenketekst | `--typography-family-default` | Normal (`--typography-weight-normal`) | `--size-16` (16px) |

### Farge

| Element | Tilstand | Token |
|---------|----------|-------|
| Tekst | Default / Hover | `--color-foreground-action` |
| Fokusring | Focus | `--color-border-focus-ring` |
| Fokusring-bakgrunn | Focus | `--color-background-canvas` |

<Note>
  Focus-ringen bygges av to stablede `box-shadow`-lag (`--color-background-canvas` innerst,
  `--color-border-focus-ring` ytterst) pluss en svak bakgrunnstone fra
  `color-mix(in srgb, var(--color-border-focus-ring) 5%, transparent)` — samme mønster
  som brukes på skjemafeltene.
</Note>

### Variant-definisjon

Ingen variant-akser i kode — `State` dekkes av CSS-pseudoklasser, ikke en `Record<...>`-mapping:

```css
.link:hover {
  text-decoration: none;
}

.link:focus-visible {
  outline: none;
  background: color-mix(in srgb, var(--color-border-focus-ring) 5%, transparent);
  box-shadow:
    0 0 0 3px var(--color-background-canvas),
    0 0 0 6px var(--color-border-focus-ring);
}
```

### Komponent-API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | — | Lenketeksten (påkrevd). |
| `...rest` | `AnchorHTMLAttributes<HTMLAnchorElement>` | — | Alle native `a`-attributter (`href`, `target`, `rel`, `onClick`, osv.) spres på root-elementet. |

### Eksempler

```tsx
// Standard
<Link href="#">This is a link</Link>

// I løpende tekst
<p>
  Les mer om designsystemet i <Link href="/docs">dokumentasjonen</Link> før du går videre.
</p>

// Ekstern lenke
<Link href="https://example.com" target="_blank" rel="noreferrer">
  Ekstern lenke
</Link>
```

## Tilgjengelighet

- Bruker native `<a>` — får tastaturfokus og aktivering (Enter) gratis.
- Synlig fokusindikator via `:focus-visible` (dobbel box-shadow-ring), ikke kun
  browserens default `outline`.
- Understrek som permanent visuell markør (fjernes kun på hover) — lenker skal ikke
  identifiseres på farge alene.
- `href` er ikke påkrevd i typen, men komponenten er meningsløs uten — sett alltid
  `href` i praksis.
