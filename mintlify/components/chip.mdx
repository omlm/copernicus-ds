## Oversikt

Kompakt, avvisbar chip for tagger, filtre, statuser eller multi-select-verdier.
Komponenten har **20 varianter** i Figma, bygget fra 4 egenskaper — men kun 2 av
dem (`Tone`, `Emphasis`) påvirker fargen. `Size` har i dag bare én verdi (Medium)
og `is Dismissable` legger kun til/fjerner ikonet, uten å endre farge.

## Anatomi

```
Chip (SPAN) — inline-flex, gap: 4px, padding: 4px 12px, radius: 999px
├── Label (TEXT)
└── Dismiss (BUTTON, Lucide "X") — vises når is Dismissable = Yes
```

## Varianter

### Egenskaper (Figma)

| Property | Values | Default | Notes |
|----------|--------|---------|-------|
| **Tone** (Variant) | Neutral, Info, Success, Danger, Warning | Neutral | Fargefamilie. |
| **Emphasis** (Variant) | Strong, Weak | Strong | Strong = fylt, Weak = lys bakgrunn med border. |
| **Size** (Variant) | Medium | Medium | Kun én verdi i dag — ingen `size`-prop i kode. |
| **is Dismissable** (Boolean) | No, Yes | No | Viser et X-ikon for å fjerne chip-en. |
| **Label** (Text) | string | "Label" | Tekstinnhold. |

5 (Tone) × 1 (Size) × 2 (Emphasis) × 2 (is Dismissable) = 20 varianter.

### Fargetokens

Hver `Tone` peker på et eget `--color-system-<tone>-*`-sett (`strong`,
`on-strong`, `weak`, `on-weak`, `weak-border`), delt med andre komponenter som
`Badge` og `Alert`. Ingen chip-spesifikke tokens — kun de globale
`color-system-*`-tokenene.

### Komponent-API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `tone` | `"neutral" \| "info" \| "success" \| "danger" \| "warning"` | `"neutral"` | Fargefamilie. |
| `emphasis` | `"strong" \| "weak"` | `"strong"` | Visuell tyngde — strong = fylt, weak = lys m/ border. |
| `dismissable` | `boolean` | `false` | Viser et X-ikon (Lucide) for å lukke chip-en. |
| `onDismiss` | `(event: MouseEvent<HTMLButtonElement>) => void` | — | Kalles når X-ikonet trykkes. Når satt blir X-en en interaktiv knapp; ellers er den kun dekorativ. Finnes ikke som Figma-egenskap. |
| `dismissLabel` | `string` | `"Fjern"` | Tilgjengelig etikett på lukk-knappen. Finnes ikke som Figma-egenskap. |
| `children` | `ReactNode` | — | Chip-innhold (påkrevd). |
| `...rest` | `HTMLAttributes<HTMLSpanElement>` | — | Alle native span-attributter spres på root-elementet. |

### Eksempler

```tsx
// Neutral (default)
<Chip>Label</Chip>

// Semantiske toner
<Chip tone="info">Info</Chip>
<Chip tone="success">Success</Chip>
<Chip tone="danger">Danger</Chip>
<Chip tone="warning">Warning</Chip>

// Weak-utgave
<Chip tone="info" emphasis="weak">Info</Chip>

// Avvisbar, ikke-interaktiv (kun dekorativt ikon)
<Chip dismissable>Tag</Chip>

// Avvisbar, interaktiv
<Chip dismissable onDismiss={() => removeTag(id)}>Tag</Chip>
```

## Tilgjengelighet

- Renderes som `<span>` — ikke fokuserbar eller interaktiv i seg selv.
- Dismiss-ikonet er **kun** en ekte, tastaturtilgjengelig `<button>` når
  `onDismiss` er satt (`aria-label` fra `dismissLabel`, default "Fjern").
  Uten `onDismiss` er ikonet dekorativt (`aria-hidden`), for å unngå
  fokuserbare elementer uten funksjon.
- Fargekontrast: `Warning`/`Strong` bruker mørk tekst (`#000000`) på oransje
  bakgrunn for å opprettholde kontrast — se fargematrisen over.

## Design–kode-paritet

| Aspekt | Figma | Kode | Status |
|--------|-------|------|--------|
| Tone → `tone` | Neutral/Info/Success/Danger/Warning | `neutral`/`info`/`success`/`danger`/`warning` | ✅ Samsvarer |
| Emphasis → `emphasis` | Strong/Weak | `strong`/`weak` | ✅ Samsvarer |
| is Dismissable → `dismissable` | No/Yes | `boolean` | ✅ Samsvarer |
| Size | Medium (eneste verdi) | Ingen `size`-prop | ⚠️ Ikke eksponert i kode — kun én verdi finnes i Figma i dag |
| Label → `children` | Text | `ReactNode` | ✅ Samsvarer |
| — | Ingen tilsvarende egenskap | `onDismiss`, `dismissLabel` | ➕ Kode-only, for tilgjengelig interaktivitet |
