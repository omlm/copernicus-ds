## Oversikt

Avkrysningsboks for uavhengige, ikke-gjensidig-utelukkende valg (i motsetning til
`RadioButton`, der kun ett valg kan være aktivt om gangen). Komponenten har
**4 varianter** i Figma, bygget fra 2 variant-egenskaper (`is Selected` × `State`).

## Anatomi

```
Checkbox (LABEL) — flex row, gap: var(--spacing-16), min-height: var(--size-40)
├── input[type="checkbox"] (visuelt skjult, men fokuserbar)
├── Control (SPAN, aria-hidden) — 24px kvadrat, 4px padding, 1px border, radius 4px
│   └── Check (ikon, Lucide "Check") — synlig kun når checked
└── Label (SPAN) — tekstinnhold
```

## Varianter

### Egenskaper (Figma)

| Property | Values | Default | Notes |
|----------|--------|---------|-------|
| **is Selected** (Variant) | No, Yes | No | Om boksen er krysset av. |
| **State** (Variant) | Default, Focus | Default | `Focus` er `:focus-visible` i kode, ikke en prop. |

2 (is Selected) × 2 (State) = 4 varianter.

<Note>
  Figma-komponenten har ingen `Label`-tekstegenskap — etiketten er en del av
  layouten rundt boksen og styres i kode via `children`, ikke via en Figma
  component-property.
</Note>


### Variant-definisjon

Checkbox har ingen variant-`Record`-mapping som `Button`/`Chip` — `is Selected`
og `State` er ikke egne props, men følger direkte av den native inputens
`checked`- og `:focus-visible`-tilstand via CSS-selektorer:

```css
.input:checked ~ .control { background: var(--color-foreground-primary); }
.input:checked ~ .control .check { opacity: 1; }
.input:focus-visible ~ .control { box-shadow: 0 0 0 3px var(--color-background-canvas), 0 0 0 6px var(--color-border-focus-ring); }
```

### Komponent-API

| Prop | Type | Default | Description |
|------|------|---------|--------------|
| `children` | `ReactNode` | — | Etiketten ved siden av avkrysningsboksen (påkrevd). |
| `disabled` | `boolean` | `false` | Ikke-interaktiv, `opacity: 0.5` og `cursor: not-allowed`. |
| `checked` | `boolean` | — | Arvet fra native input — styrt eller ustyrt bruk støttes begge. |
| `...rest` | `Omit<InputHTMLAttributes<HTMLInputElement>, "type" \| "children">` | — | Alle native input-attributter unntatt `type` (fast `"checkbox"`) og `children`, spres på selve inputen. |

### Eksempler

```tsx
// Ustyrt/styrt bruk
const [checked, setChecked] = useState(false);
<Checkbox checked={checked} onChange={(e) => setChecked(e.target.checked)}>
  This is a choice
</Checkbox>

// Forhåndskrysset
<Checkbox checked onChange={() => {}}>Checked</Checkbox>

// Deaktivert
<Checkbox disabled>Label</Checkbox>

// Flere uavhengige valg
{["a", "b", "c"].map((v) => (
  <Checkbox key={v} value={v} checked={values.includes(v)} onChange={() => toggle(v)}>
    This is a choice
  </Checkbox>
))}
```

## Tilgjengelighet

- Bruker native `<input type="checkbox">` pakket i `<label>` — hele
  label-arealet er klikkbart, og inputen får tastaturfokus og aktivering
  (Space) gratis.
- Den ekte inputen er visuelt skjult (`clip-path: inset(50%)`), ikke
  `display: none` — den forblir i tab-rekkefølgen og leses av skjermlesere.
- Den visuelle boksen (`.control`) er `aria-hidden` siden den kun er en
  dekorativ representasjon av inputens tilstand.
- Synlig fokusindikator via `:focus-visible` (dobbel ring, ikke bare
  fargeendring) — fungerer også for brukere med redusert fargesyn.
- `disabled` setter `cursor: not-allowed` og arves fra native `disabled`-attributt.

## Design–kode-paritet

| Aspekt | Figma | Kode | Status |
|--------|-------|------|--------|
| is Selected → `checked` | No/Yes | `boolean` (native input) | ✅ Samsvarer |
| State=Focus | Figma-effekt (drop-shadow) | `:focus-visible` med `box-shadow` | ✅ Dekket (ikke prop) |
| Label | Ingen tekstegenskap i Figma | `children` (påkrevd prop) | ➕ Kode-only, styrt av forbruker |
