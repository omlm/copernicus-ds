## Oversikt

Primær handlingskontroll. Brukes for handlinger brukeren utfører (send inn, fortsett, avvis).
For navigasjon som endrer URL, bruk `Link` i stedet. Komponenten har **90 varianter** i Figma,
bygget fra 4 variant-egenskaper (Type × Size × State × Tone), pluss to uavhengige
boolske ikon-egenskaper som ikke multipliserer variant-antallet.

## Anatomi

```
Button (COMPONENT) — horizontal auto-layout, gap: var(--button-gap)=4px [fixed-height]
├── Left Icon (INSTANCE) — vises når Show Left Icon = Yes
│   └── Icon / <navn> (INSTANCE)
│       └── Vector (VECTOR)
├── Label (TEXT)
└── Right Icon (INSTANCE) — vises når Show Right Icon = Yes
    └── Icon / <navn> (INSTANCE)
        └── Vector (VECTOR)
```

## Varianter

### Egenskaper (Figma)

| Property | Values | Default | Notes |
|----------|--------|---------|-------|
| **Type** (Variant) | Primary, Secondary, Tertiary | Primary | Endrer visuell behandling |
| **Size** (Variant) | Large, Medium, Small | Large | Large=48px, Medium=32px, Small=24px |
| **State** (Variant) | Default, Hover, Active, Focus, Disabled | Default | Interaksjonstilstand (ikke en prop i kode) |
| **Tone** (Variant) | Neutral, Danger | Neutral | Overstyrer Type-fargen for destruktive handlinger, uavhengig av Type |
| **Show Left Icon** (Boolean) | No, Yes | No | Ikon før etiketten |
| **Show Right Icon** (Boolean) | No, Yes | No | Ikon etter etiketten |
| **Label** (Text) | string | "Label" | Tekstinnhold |

3 (Type) × 3 (Size) × 5 (State) × 2 (Tone) = 90 varianter. Show Left/Right Icon er
uavhengige boolske egenskaper på hver variant (kan begge være `true` samtidig) — de er
ikke en egen variant-akse, og påvirker derfor ikke variant-antallet.

### Fargematrise — bestemt av Type × State × Tone

Bakgrunns- og tekstfarge avhenger **kun** av `Type`, `State` og `Tone` (identisk på tvers
av størrelse og ikon-flagg).

<Note>
  Focus deler bakgrunn med Default; tilstanden vises via en focus-ring (se kode: `outline` på `:focus-visible`).
  For `Tone=Danger` er Disabled bevisst identisk med `Tone=Neutral` sin disabled-farge (samme
  disabled-tokens brukes uansett tone) — se `.danger.primary:disabled` / `.danger.secondary:disabled`
  i `Button.module.css`.
</Note>

### Variant-definisjon

```tsx
const variantClass: Record<ButtonVariant, string> = {
  primary: styles.primary,
  secondary: styles.secondary,
  tertiary: styles.tertiary,
};

const sizeClass: Record<ButtonSize, string> = {
  small: styles.sizeSmall,
  medium: styles.sizeMedium,
  large: styles.sizeLarge,
};
```

### Komponent-API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"primary" \| "secondary" \| "tertiary"` | `"primary"` | Visuell stil. Bruk kun én primary-handling per visning. |
| `size` | `"small" \| "medium" \| "large"` | `"large"` | Knappestørrelse (large=48px, medium=32px, small=24px). |
| `tone` | `"neutral" \| "danger"` | `"neutral"` | `"danger"` farger knappen rødt for destruktive handlinger, uavhengig av `variant`. |
| `trailingIcon` | `boolean \| ReactNode` | `false` | Vis trailing-ikon. `true` = standard pil (`ArrowRight`), eller send et eget element. |
| `trailingIconName` | `IconName` | — | Velg trailing-ikon fra hele Lucide-settet via navn (overstyrer pilen). |
| `leadingIcon` | `boolean \| ReactNode` | `false` | Vis leading-ikon (før etiketten). `true` = standard pil, eller send et eget element. |
| `leadingIconName` | `IconName` | — | Velg leading-ikon fra hele Lucide-settet via navn. |
| `disabled` | `boolean` | `false` | Ikke-interaktiv (arvet fra native button). |
| `children` | `ReactNode` | — | Knappe-etikett (påkrevd). |
| `...rest` | `ButtonHTMLAttributes<HTMLButtonElement>` | — | Alle native button-attributter (`onClick`, `type`, `name`, `aria-*`, osv.) spres på root-elementet. |

### Eksempler

```tsx
// Primary (default)
<Button>Label</Button>

// Secondary
<Button variant="secondary">Label</Button>

// Tertiary
<Button variant="tertiary">Label</Button>

// Destruktiv handling (tone overstyrer variant-fargen)
<Button tone="danger">Slett</Button>

// Med trailing-pil
<Button trailingIcon>Neste</Button>

// Med leading-pil
<Button leadingIcon>Tilbake</Button>

// Bytt ut ikonet (Lucide)
<Button trailingIconName="heart">Lik</Button>

// Størrelser
<Button size="large">Large</Button>
<Button size="medium">Medium</Button>
<Button size="small">Small</Button>

// Disabled
<Button disabled>Label</Button>
```

## Tilgjengelighet

- Bruker native `<button>` — får tastaturfokus og aktivering (Enter/Space) gratis.
- Synlig fokusindikator via `:focus-visible` (`outline: 2px solid var(--color-foreground-action)`).
- `disabled` setter `cursor: not-allowed` og fjerner interaksjon.
- Ingen a11y-annotasjoner funnet i Figma — vurder å legge til kontrast-/aria-notater i Dev Mode.
