## Oversikt

Segmentert valggruppe (også kjent som "segmented control") der nøyaktig ett
alternativ er aktivt om gangen — typisk brukt for visningsbytter (liste/rutenett/kart)
eller andre gjensidig utelukkende valg med få alternativer. Implementert som
`role="radiogroup"` med piltast-navigasjon.

Frame **"Toggle group"** (node `3203:8`) i Figma er komponert av **3 instanser**
av komponentsettet **"Toggle item"** (node `3203:7`) — parent-frame har ingen egne
component properties. Variant-aksen (valgt/ikke valgt) ligger på "Toggle item".

## Anatomi

```
Toggle group (DIV, role="radiogroup") — inline-flex, gap: var(--spacing-4),
                                          padding: var(--spacing-4), radius: var(--radius-999)
├── Toggle item (BUTTON, role="radio") (INSTANCE) — "is Selected=No"
├── Toggle item (BUTTON, role="radio") (INSTANCE) — "is Selected=Yes"
└── Toggle item (BUTTON, role="radio") (INSTANCE) — "is Selected=No"
```

## Varianter

### Egenskaper (Figma) — "Toggle item" (node 3203:7)

| Property | Values | Default | Notes |
|----------|--------|---------|-------|
| **is Selected** (Variant) | Yes, No | No | Om alternativet er det aktive valget i gruppa. |

1 (is Selected) = 2 varianter på "Toggle item". Parent-frame "Toggle group" har
ingen egne component properties — antall og innhold i alternativene styres av
hvor mange "Toggle item"-instanser som legges inn.

## Implementasjon

### Kildefiler

| File | Role |
|------|------|
| `src/components/ToggleGroup/ToggleGroup.tsx` | Komponent + eksporterte typer (`ToggleGroup`, `ToggleGroupOption`) |
| `src/components/ToggleGroup/ToggleGroup.module.css` | CSS Modules (token-bundet via `var()`) |
| `src/components/ToggleGroup/ToggleGroup.stories.tsx` | Storybook stories + argTypes |

### Import

```tsx
import { ToggleGroup, type ToggleGroupProps, type ToggleGroupOption } from "src/components";
```

### Variant-definisjon

```tsx
className={[styles.item, isSelected && styles.selected].filter(Boolean).join(" ")}
```

### Komponent-API

**ToggleGroupOption**

| Felt | Type | Description |
|------|------|-------------|
| `value` | `string` | Verdien valget representerer. |
| `label` | `ReactNode` | Synlig etikett (Figma: "Label"). |

**ToggleGroupProps**

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `options` | `ToggleGroupOption[]` | — | Valgene, i rekkefølge (påkrevd). |
| `defaultValue` | `string` | første `option.value` | Valgt verdi ved første rendring (ukontrollert). |
| `value` | `string` | — | Valgt verdi (kontrollert). Brukes sammen med `onChange`. |
| `onChange` | `(value: string) => void` | — | Kalles når brukeren velger et annet alternativ. |
| `aria-label` | `string` | — | Tilgjengelig navn for gruppen. |
| `...rest` | `Omit<HTMLAttributes<HTMLDivElement>, "onChange">` | — | Alle native div-attributter (unntatt `onChange`, som er omdefinert) spres på root-elementet. |

### Eksempler

```tsx
// Ukontrollert — første valg aktivt
<ToggleGroup
  aria-label="Velg visning"
  options={[
    { value: "list", label: "Liste" },
    { value: "grid", label: "Rutenett" },
    { value: "map", label: "Kart" },
  ]}
/>

// Kontrollert
const [value, setValue] = useState("grid");
<ToggleGroup
  aria-label="Velg visning"
  options={options}
  value={value}
  onChange={setValue}
/>
```

## Tilgjengelighet

- Implementert som `role="radiogroup"` med hvert alternativ som `role="radio"`
  og `aria-checked` — samme mønster som en radioknapp-gruppe, men visuelt
  segmentert.
- Full piltast-navigasjon (venstre/opp og høyre/ned) flytter fokus og velger
  alternativet samtidig, med roving tabindex (kun valgt item har `tabIndex={0}`).
- Krever `aria-label` (eller ekstern `aria-labelledby` via `...rest`) for at
  gruppens formål skal være tydelig for skjermlesere, siden det ikke finnes
  noen synlig gruppe-etikett i komponenten selv.
- Synlig fokusindikator via `:focus-visible` (`box-shadow` med
  `--color-border-focus-ring`).
