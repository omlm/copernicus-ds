## Oversikt

Ekspanderbart panel for å vise eller skjule innhold — typisk brukt for FAQ-er,
detaljseksjoner eller annen informasjon som ikke trenger å være synlig hele
tiden. Bygget direkte på native `<details>`/`<summary>`, som gir åpne/lukke-logikk
og tastaturstøtte gratis fra nettleseren. Komponenten har **2 varianter** i Figma
(Closed, Open) på én egenskap (`State`) — det finnes ingen boolske eller
tekst-egenskaper.

## Anatomi

```
Details (DETAILS) — padding: var(--spacing-16), border, radius: var(--radius-12)
├── Summary (SUMMARY) — flex, justify-content: space-between
│   ├── Summary label (TEXT)
│   └── Chevron (ICON, Lucide "chevron-down") — roterer 180° når åpen
└── Content (DIV) — vises kun når State=Open
```

## Varianter

### Egenskaper (Figma)

| Property | Values | Default | Notes |
|----------|--------|---------|-------|
| **State** (Variant) | Closed, Open | Closed | Styres av `<details open>` i kode, ikke en komponent-prop. |

1 (State) = 2 varianter. Ingen boolske eller tekst-egenskaper i Figma-komponentsettet.

<Note>
  I kode finnes ikke `State` som prop — den native `open`-attributten (og
  brukerens klikk på `<summary>`) avgjør tilstanden. `open` kan likevel settes
  eksplisitt eller kontrolleres via `...rest` siden `DetailsProps` utvider
  `DetailsHTMLAttributes<HTMLDetailsElement>`.
</Note>

### Variant-definisjon

Ingen `Record<...>`-mapping er nødvendig — komponenten har kun én visuell
tilstand som styres av CSS-attributtselektoren:

```css
.details[open] .chevron {
  transform: rotate(180deg);
}
```

### Komponent-API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `summary` | `ReactNode` | — | Den alltid synlige overskriften (påkrevd). |
| `children` | `ReactNode` | — | Innholdet som vises når panelet er åpent (påkrevd). |
| `...rest` | `DetailsHTMLAttributes<HTMLDetailsElement>` | — | Alle native `details`-attributter (`open`, `onToggle`, `className`, osv.) spres på root-elementet. |

### Eksempler

```tsx
// Lukket (default)
<Details summary="Summary title">
  Dette er innholdet som vises når panelet åpnes.
</Details>

// Åpen fra start
<Details summary="Summary title" open>
  Dette er innholdet som vises når panelet åpnes.
</Details>

// Flere paneler etter hverandre (enkel "accordion")
<div style={{ display: "flex", flexDirection: "column", gap: 8 }}>
  <Details summary="Første panel">Innhold 1</Details>
  <Details summary="Andre panel">Innhold 2</Details>
  <Details summary="Tredje panel">Innhold 3</Details>
</div>
```

## Tilgjengelighet

- Bruker native `<details>`/`<summary>` — tastaturfokus, aktivering (Enter/Space)
  og skjermleser-semantikk (implisitt ekspander-rolle) kommer gratis fra nettleseren.
- Nettleserens egen markør (`::-webkit-details-marker`) er skjult og erstattet
  med en Lucide-chevron som er dekorativ (`aria-hidden="true"`) — tilstanden
  formidles allerede av `<details>` sin native semantikk.
- Synlig fokusindikator på `<summary>` via `:focus-visible`
  (`box-shadow` med `--color-border-focus-ring`).
- Chevron-rotasjonen respekterer `prefers-reduced-motion: reduce`
  (overgangen fjernes helt).
