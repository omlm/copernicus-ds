## Oversikt

Flerlinjet tekstfelt med etikett og hjelpetekst — et native `textarea` med
samme mønster og tilstander som `Input` (Default/Filled/Focus/Error/Disabled).
Komponenten har **5 varianter** i Figma, én per `State`.

## Anatomi

```
Textarea (DIV) — vertical layout, gap: var(--spacing-8)
├── Label (LABEL) — vises når label er satt
├── Textarea (TEXTAREA) — padding: var(--spacing-16), radius: var(--radius-12), rows=4
└── Description/Error (P) — vises når description eller error er satt
```

## Varianter

### Egenskaper (Figma)

| Property | Values | Default | Notes |
|----------|--------|---------|-------|
| **State** (Variant) | Default, Focus, Filled, Error, Disabled | Default | Avledet av CSS/DOM-tilstand i kode, ikke en egen prop |

5 varianter totalt (én per `State`). Ingen componentProps (Label/Description
tekstegenskaper) er eksponert på dette Figma-komponentsettet, i motsetning til
`Input` — i kode styres begge via vanlige React-props (`label`, `description`).

### Tilstandsmapping (Figma State → kode)

| Figma State | Kode-mekanisme |
|-------------|----------------|
| Default | Ingen spesialklasse — grunnstilen |
| Focus | `:focus-visible` |
| Filled | Naturlig DOM-tilstand (verdi satt via `value`/`defaultValue`) — ingen egen visuell klasse |
| Error | `[aria-invalid="true"]`, styrt av `error`-propen |
| Disabled | `:disabled`, styrt av `disabled`-propen |

## Implementasjon

### Kildefiler

| File | Role |
|------|------|
| `src/components/Textarea/Textarea.tsx` | Komponent + eksportert type |
| `src/components/Textarea/Textarea.module.css` | CSS Modules (token-bundet via `var()`) |
| `src/components/Textarea/Textarea.stories.tsx` | Storybook stories + argTypes |

### Import

```tsx
import { Textarea, type TextareaProps } from "src/components";
```

### Variant-definisjon

Ingen `Record<...>`-variant-mapping — tilstandene er rene CSS-selektorer
(`:focus-visible`, `[aria-invalid="true"]`, `:disabled`) på `.field`-klassen
i `Textarea.module.css`, samme mønster som `Input`.

### Komponent-API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `ReactNode` | — | Etikett over feltet. Rendres kun når satt. |
| `description` | `ReactNode` | — | Hjelpetekst under feltet. Skjules når `error` er satt. |
| `error` | `ReactNode` | — | Feilmelding. Når satt: rød border (`aria-invalid="true"`) og meldingen vises i stedet for `description`. |
| `rows` | `number` | `4` | Antall synlige tekstlinjer (native `textarea`-attributt). |
| `disabled` | `boolean` | `false` | Ikke-interaktiv, halv opasitet, `resize` slås av. |
| `id` | `string` | auto-generert (`useId`) | Kobles til `label` via `htmlFor`. |
| `...rest` | `TextareaHTMLAttributes<HTMLTextAreaElement>` | — | Alle native textarea-attributter (`placeholder`, `value`, `onChange`, osv.) spres på feltet. |

### Eksempler

```tsx
// Tom (default)
<Textarea label="Label" placeholder="Placeholder" description="Textarea description" />

// Utfylt
<Textarea
  label="Label"
  defaultValue="This is the text the user has written."
/>

// Feiltilstand
<Textarea
  label="Label"
  defaultValue="This is the text the user has written."
  error="This is an error message"
/>

// Deaktivert
<Textarea label="Label" disabled />
```

## Tilgjengelighet

- Bruker native `<textarea>` — får tastaturinteraksjon og skjermleserstøtte gratis.
- `label` kobles til feltet via `htmlFor`/`id` (auto-generert med `useId` hvis
  `id` ikke er satt).
- `aria-invalid="true"` settes automatisk når `error` er satt.
- `aria-describedby` peker på hjelpeteksten/feilmeldingen slik at skjermlesere
  leser den sammen med feltet.
- Synlig fokusring via `:focus-visible` (border + box-shadow), ikke kun
  fargeendring.
- Ingen a11y-annotasjoner funnet i Figma — vurder å legge til kontrast-/aria-notater
  i Dev Mode.
